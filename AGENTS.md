Follow PROTOCOL.md for scientific scope and PUBLICATION.md for sanitized placeholders and provenance. Original runtime history remains private; never merge or push it into this public repository.

Stage explicit paths and inspect diffs. Preserve measured results and distinguish original execution SHA from sanitized/public commits. Use local ignored configuration for deployment. New experimental repositories remain private unless the user explicitly authorizes publication. Do not force-push or overwrite other contributors' work.
